# HarborWMS 演示路径（P0）

数据在浏览器 localStorage（键 `wms-demo-v1`）。右上角可重置。

## A. 收货上架 → 发货

1. **入库管理** → `INB-2026-0100`（ERP 同步采购单，预期毛巾 100）。
2. 第一行实收填 `98` → **收货**。库存只增加 98，且在 `RECV-01` 暂存（不可分配）。
3. **上架确认** → 库存进入拣货/存储位后才可预占。
4. 可选：**短收关闭** 结清未收 2 件。
5. 再点「重复同步」：仍只有一张单（幂等）。
6. **出库管理** → `OUT-2026-0200` → **预占分配** → **确认拣货** → **复核包装** → **确认发货**。
7. 发货后生成包裹追踪号与运费事件；重复发货会被拒绝。

## B. 运输 + 循环箱

1. 出库详情对包裹点 **创建运输任务**。
2. 选择可用车辆/司机 → **派车** → **发车** → **签收**（轨迹标注为模拟）。
3. 勾选若干 TOTE → **发放**；到 **循环箱与资产** 用「归还 2」验证部分归还与剩余持有。

## C. 运费对账

1. 先完成至少两笔发货以产生预计费用（或使用种子后自走 A）。
2. **费用与对账** → **填入三行演示 CSV** → 导入。
3. **自动匹配**：一行一致、一行差额、一行无证据。
4. 对差异行「接受对方金额」或「挂起争议」→ **审批可结算行**（仅 MATCHED/ACCEPTED 进入结算）。

## 三语与权限

- 顶栏切换中/英/西：停留当前页，业务状态不变。
- 角色切到 **Aurora ReadOnly**：只能看到极光家居货主数据。
